# PayFix AI — Digital Payment Dispute and Refund Management Platform

## Project Overview

PayFix AI is a Technical Business Analyst / IT Business Analyst portfolio project focused on improving digital payment dispute, payment failure, refund and case management processes.

The project demonstrates how a payment operations team can move from manual, fragmented and spreadsheet-based tracking to a more structured operating model using business analysis, data analysis, process improvement, business rules, AI-assisted triage, SLA monitoring, UAT planning and a working Streamlit prototype.

The dataset used in this project is synthetic and created for portfolio demonstration purposes. It does not contain real customer, bank, merchant or transaction data.

---

## Business Problem

Digital payment dispute and refund teams often face issues such as:

* Manual case tracking
* Delayed refund decisions
* SLA breaches
* Inconsistent dispute classification
* Limited visibility of root causes
* Repeated manual investigation
* Inconsistent customer communication
* Need for human oversight in fraud, high-risk and high-value cases

---

## Project Objective

The objective of this project was to design and build a portfolio-level MVP that demonstrates how a Technical Business Analyst can:

* Analyse a fintech/payment operations problem
* Use Excel to identify dispute and refund trends
* Create structured BA documentation
* Define business rules and refund eligibility logic
* Design As-Is and To-Be process improvements
* Prepare UAT test cases and defect logs
* Plan go-live, rollback, training and benefits realisation
* Build a working Streamlit prototype using Python

## How to Run the Prototype

Open the prototype folder:

```bash
cd "03 Prototype and System Design"
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Go to the app folder:

```bash
cd app
```

Run the Streamlit app:

```bash
python -m streamlit run app.py
```
